# AI 기반 자연어 처리 Discord 봇 프로젝트

## 프로젝트 개요

이 프로젝트는 **자연어 이해(NLU)**와 **동적 커맨드 생성** 기능을 결합한 고급 Discord 봇을 개발하는 것입니다. 사용자가 대화만으로 새로운 명령어를 생성하고, AI가 자동으로 응답을 생성하며, 봇이 실시간으로 이를 실행할 수 있는 시스템을 구축합니다.

## 핵심 기능

### 1. 자연어 처리 (NLP/NLU)
- **OpenAI GPT-4** API 통합으로 자연스러운 대화 처리
- **의도 분석 (Intent Detection)**: 사용자 요청의 목적 파악
- **엔터티 추출 (Entity Extraction)**: 중요 정보 자동 추출
- **컨텍스트 유지**: 대화 히스토리를 통한 연속적 상호작용

### 2. 동적 커맨드 생성
- **실시간 슬래시 커맨드 등록**: `/추가` 명령어로 새 커맨드 생성
- **모달 인터페이스**: 사용자 친화적 입력 양식
- **AI 기반 응답 생성**: OpenAI API를 통한 자동 응답 템플릿 생성
- **즉시 동기화**: Discord 서버에 실시간 반영

### 3. 권한 관리 시스템
- **역할 기반 접근 제어 (RBAC)**: 사용자 역할별 기능 제한
- **커맨드별 권한 설정**: 세분화된 권한 관리
- **보안 검증**: 입력 검증 및 SQL 인젝션 방지

### 4. 데이터베이스 관리
- **SQLAlchemy ORM**: PostgreSQL/SQLite 지원
- **메타데이터 저장**: 커맨드 정보, 사용자 설정, 대화 기록
- **백업 및 복구**: 자동 데이터 백업 시스템
